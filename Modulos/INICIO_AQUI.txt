  👤 GESTIÓN DE USUARIOS
  ─────────────────────

    Crear usuario sin HWID:
    $ python3 user_cli.py create usuario1 password123

    Crear usuario con HWID:
    $ python3 user_cli.py create usuario2 pass456 --hwid "ABC123"

    Listar todos:
    $ python3 user_cli.py list

    Ver detalles de uno:
    $ python3 user_cli.py info usuario1

    Agregar HWID después:
    $ python3 user_cli.py register-hwid usuario1 "ABC123"

    Desactivar usuario:
    $ python3 user_cli.py toggle deactivate usuario1

    Eliminar usuario:
    $ python3 user_cli.py delete usuario1 -f


  🖥️ EJECUTAR PROXY
  ─────────────────

    $ python3 wsproxy.py

    Puerto personalizado:
    $ python3 wsproxy.py -p 8080

    IP y puerto específicos:
    $ python3 wsproxy.py -b 192.168.1.100 -p 80

┃  🔐 CÓMO FUNCIONA LA AUTENTICACIÓN                                      ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

  El cliente envía 4 headers HTTP obligatorios:

    X-User: <nombre_usuario>        ← Nombre de usuario
    X-Pass: <contraseña>            ← Contraseña
    X-HWID: <hardware_id>           ← ID del hardware (si el usuario lo requiere)
    X-Real-Host: <destino:puerto>   ← Donde conectarse

  El proxy valida:
    1. ¿El usuario existe?
    2. ¿La contraseña es correcta?
    3. ¿Tiene HWID registrado? Si sí, ¿coincide?
    4. ¿El usuario está activo?

  Si TODO es correcto → Conecta al destino (X-Real-Host)
  Si ALGO falla → Devuelve 401 Unauthorized

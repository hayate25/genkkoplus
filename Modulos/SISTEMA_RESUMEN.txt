📋 CASOS DE USO:
═══════════════════════════════════════════════════════════════════════════

CASO 1: Usuario sin HWID
────────────────────────
Creación:    python3 user_cli.py create alice pass123
Conexión:    curl -H "X-User: alice" \
                  -H "X-Pass: pass123" \
                  -H "X-Real-Host: 127.0.0.1:22" \
                  http://proxy:80
Resultado:   ✅ Conectado (HWID opcional)


CASO 2: Usuario con HWID obligatorio
─────────────────────────────────────
Creación:    python3 user_cli.py create bob pass456 --hwid "PC-12345"
Conexión OK: curl -H "X-User: bob" \
                  -H "X-Pass: pass456" \
                  -H "X-HWID: PC-12345" \
                  -H "X-Real-Host: 127.0.0.1:22" \
                  http://proxy:80
Resultado:   ✅ Conectado

Conexión con HWID incorrecto:
                  -H "X-HWID: WRONG-ID" \
Resultado:   ❌ 401 Unauthorized


CASO 3: Agregar HWID a usuario existente
─────────────────────────────────────────
                  python3 user_cli.py register-hwid alice "LAP-67890"

Ahora alice necesita proporcionar ese HWID en futuras conexiones


⚙️ CONFIGURACIÓN IMPORTANTE:
═══════════════════════════════════════════════════════════════════════════

En wsproxy.py, línea 17:

USE_USER_SYSTEM = True   ← ACTIVAR NUEVO SISTEMA
# USE_USER_SYSTEM = False ← DESACTIVAR (volver a contraseña global)

Para cambiar puerto de escucha:
    python3 wsproxy.py -p 8080

Para cambiar IP de escucha:
    python3 wsproxy.py -b 192.168.1.100 -p 80
